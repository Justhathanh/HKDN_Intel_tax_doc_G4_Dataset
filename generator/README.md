# Generator package

Planned Python package for creating synthetic tax documents.

Implementation order:
1. Define canonical data contracts with THTAX Core.
2. Implement Document Type Registry.
3. Implement deterministic data factory (seedable).
4. Implement per-type validation.
5. Implement XML/PDF/image exporters.
6. Generate Ground Truth and manifest.
7. Add CLI and automated tests.

No runtime implementation is included in this scaffold yet.
