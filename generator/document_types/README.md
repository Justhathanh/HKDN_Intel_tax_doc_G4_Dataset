# Document Types

Each document type should define:
- stable registry key;
- human-readable name and category;
- applicable canonical fields;
- required/optional field rules;
- input validation;
- XML mapping (only when confirmed);
- visual template mapping;
- Ground Truth mapping.

Initial candidates: invoice_gtgt, invoice_sales, invoice_adjustment, invoice_replacement, tax_payment_voucher, tax_notice, fee_receipt, pit_withholding_certificate, non_tax_document.
